# Holyshot

سایت کافه Holyshot با Express و WebSocket و ربات تلگرام برای مدیریت صداها.

## متغیرهای محیطی

- `BOT_TOKEN`: توکن ربات تلگرام (اجباری)
- `ADMIN_IDS`: شناسه عددی ادمین‌ها با کاما جداشده، مثل `12345,67890` (اجباری؛ بدون آن ربات به هیچ‌کس پاسخ نمی‌دهد)
- `PORT`: پورت سرور (پیش‌فرض 3000)
- `DATA_FILE`: مسیر فایل ذخیره صداها (پیش‌فرض `voices.json`)

## اجرا

```bash
npm install
BOT_TOKEN=... ADMIN_IDS=... node index.js
```

## دستورات ربات (فقط ادمین)

- `/addvoice` افزودن صدا
- `/deletevoice` حذف صدا با شناسه
- `/edittext` ویرایش متن صدا
- `/list` فهرست صداها
- `/cancel` لغو مکالمه فعلی

## API

- `GET /api/voices` فهرست صداها
- `GET /audio/:id` پخش فایل صوتی (از طریق سرور، بدون افشای توکن)
- WebSocket: بعد از اتصال پیام `init` با فهرست کامل می‌آید. پیام‌های `addVoice` و `deleteVoice` و `editText` برای تغییرات لحظه‌ای ارسال می‌شوند.

## نکته

روی میزبان‌هایی مثل Render دیسک موقتی است؛ برای ماندگاری واقعی از دیسک دائمی یا پایگاه داده استفاده کن.
